# 口琴音色修订 · A6C4

在App0.22/A623完整音响版上继续修订口琴，保留七片、五键、LED/OLED、曲目/歌词、蓝牙、32声部、可视化、自定义映射及设备录音回传。此次没有改变App协议、引脚或压力标定，不需要为了音色重新安装APK。没有执行硬件烧录。

## 修订依据

原72音高表来自expression_profile_v1。强力度下，二次/三次谐波权重相对基音最高约1.13/0.99，容易使口琴转为偏锐的簧管/合成音。之前E2B1的柔化实验未并入A623。此次不是只降低总音量，也不是用混响遮盖：为口琴单独生成648组音高/力度锚点，二胡的648组表项保持逐位相同。

同时分清音高表与音色表的生成职责：已有72音高的音色数据在重新生成音高映射时会保留，只有显式请求“初始化旧版音色”才恢复V1，避免后续维护时把修订音色无意覆盖。

口琴仍由六个相位相关谐波实时计算，未使用录制乐器PCM。硬件保留原来的快速振荡器；生成参数时，先分析它自身额外产生的泛音，建立六个声源到目标六个泛音的传递矩阵，再用非负最小二乘求出补偿权重。这样修正主要泛音比例，不为FPGA增加新的乘法器。高音区的目标高次谐波在12—18kHz渐弱/截止；近似声源仍有较弱的高阶残余，不宣称完全无混叠。

16,384个相位点已与独立定点参考逐一核对，648组口琴参数都检查了二次/三次谐波相对基音的上限。气息改用较低频的随机分量，放到有音高的声音后面。两条演奏路径的口琴自然微颤均约4.7Hz，避免手敲与自动播放的长音性格不同。

音量包络在约2.67ms内先上升至37.5%，再用约21.33ms渐渐丰满到持续电平；这不是等待24ms才出声，没有增加事件队列。二胡起音保持原来的曲线。完整输入到输出延迟按原先固定门限重新仿真，实板仍需要用仪器测量。

这些是针对本产品设计的参数与固定点实现，不是实测口琴校准数据。一般合成思路可参考[CMU计算机音乐教材](https://www.cs.cmu.edu/~15322/book/ch03/04.html)，自由簧的物理背景可参考[Nottingham的实验研究](https://www.cs.bu.edu/fac/snyder/TablatureWeb/ICA.PDF)；本版没有照搬其源代码，也没有声称实现完整自由簧物理模型。

## 试听方式

- “口琴_新版短句”：6秒，包含轻音、强音、短重复和长音。
- “口琴_同增益对比_先旧后新”：先6秒A623，停0.5秒，再6秒新版。前后旋律、力度与导出增益相同。
- “我和我的祖国_新版口琴_20秒”：沿用已经验收过的曲谱/原设备播放器，展示连续旋律，不重新识别歌曲。

试听由实际RTL单声部音源生成，是数字输出预览，不是喇叭录音；真实32声部排程、I2S和完整布局布线另有验证。试听统一放大到适合手机/电脑播放的电平，没有分别归一化A/B。20秒裁剪片段仅在最后10ms淡出，避免截在波形中间的啪声；原始采样与测量不作淡出处理。设备音量仍由原音量旋钮/App控制。

## 上板验证

先关闭回声、合唱和混响，以原有常用音量加载A6C4到SRAM，保持供电。分别试中音区的轻敲、重敲、长按、连续重复，随后自动播放《我和我的祖国》。重点判断起音是否不再过分突兀，强按是否依然清亮，长音是否更自然；再逐个恢复音效。原A623包和已安装Flash均保留。

数字测量能验证削顶、响度、频谱和排程，不能替代耳朵判断“是否像真实口琴”。若完全不演奏时实物仍有持续沙声，应另查功放与供电；此次没有通过软件验证来排除模拟电路噪声。
