## 任何新外设上板前的安全检查

1. 核对**实际购买模块**的数据手册、引脚丝印、供电电压、逻辑电平和板卡 3.3 V GPIO；未确认前不接电。压电片不能直接连 FPGA 引脚。
2. 外置 I²S 模块必须区分标准 I²S 与左对齐，以及 DAC/线性输出、桥接扬声器功放的不同接口；桥接扬声器负端不能接示波器地或耳机公共地。
3. 新配置只在用户在场且音量调低后写入 SRAM。当前 `board/impl/pnr/playable_demo_60k.fs` 是可回退的已听版本，不能覆盖或把新未验收版本写入 Flash。
4. 对每项赛题表述，先准备“信号路径 + 测试方法 + 原始证据 + 失败边界”。没有原始证据就写“计划中”或“仿真通过”，不能写“实测达到”。

## 外设到货后的顺序

先只做两区敲击原型，测轻/重击、串扰和重复性；再扩至七区并验证 CH7 滑杆与 EC11。外置 DAC 到货后先单独检查标准 I²S 逻辑时序和低音量发声，之后才把真实交互接入标准 I²S 四声部路径。国庆假期后借示波器/逻辑分析仪，补模拟频谱和端到端延迟证据。
