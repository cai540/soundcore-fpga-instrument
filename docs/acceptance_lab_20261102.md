# 声芯乐动：完整验收与实验室操作

配套版本：App0.22，FPGA UserCode0000A623。先SRAM测试，验收通过再写Flash。本轮构建不自动连接下载器、不修改原Flash。重新断电会回到原Flash版本，因此SRAM测试期间保持通电。

## 二、开始前的顺序

1. 沿用现有已确认的接线。本轮没有更换FPGA引脚；测量时可在ADC/MAX模块可读的引脚处夹探头，不必数FPGA封装脚。
2. 关电后固定探头。检查电源输出轨：OLED/ADC逻辑3.3V、功放供电在模块允许范围；对曾经异常的面包板电源，不凭跳帽文字认定实际电压。
3. 安装本包0.22 APK。用原来的下载线加载本包FS到SRAM，核对UserCode0000A623。不要先覆盖旧Flash。
4. 先用低音量测试七片、旋钮、滑杆、K1—K5、OLED、蓝牙和灯环。之后把音量设16，先关三种音效。
5. 手机连接后进入“设备 → 演奏工具”。能读出工具状态才开始新增功能验收；旧固件会明确提示不支持。

机身操作速查（每次短按后完全松开，不同时按两颗）：

- 普通配置页：K1降低音区，K2提高音区，K3切换口琴/二胡；旋转编码器调音量，短按编码器切换颤音。长按编码器约0.7秒进入/退出颤音深度调节，旋转调深度，闲置约5秒自动回到音量。
- 自动演奏：短按K4进入曲目页，K1/K2或旋钮选曲，短按K5开始；再按K5暂停/继续；K4停止并回普通配置。播放/暂停中长按K5约0.7秒回到曲首并暂停。
- 脱机指引：长按K4约0.7秒进入模式菜单，K1选指引、K2选示范，K5确认；再选曲、K5开始。指引时只敲亮灯的琴片，音高自动选择；K4退出。菜单中旋钮可移动选择，短按旋钮确认。
- K5灯环：播放/指引运行时亮，暂停闪烁，退出后灭；它的灯线与开关线是两个独立回路。本轮没有改变接线。

## 四、32复音：这样向评委证明

这是**32个声部**，不是35个可选音高，也不是32个按钮。测试复用原32声部引擎：每个声部有自己的相位、音高和包络，依然由硬件逐样本计算。检测暂用周期正弦，便于数清基频；普通口琴/二胡不被这种检测音替代。

1. 先停止机身/手机曲目，放开全部琴片，普通音量设16。进入“声音图景→打开复音检测”。
2. 依次点4、8、16、32。等待活动声部数稳定，听到连续复合音。32音是密集半音簇，会像和弦噪响，不是为了好听的演奏示例。
3. 在MAX模块的 **BCLK、LRC/LRCLK、DIN** 上采数字信号，逻辑分析仪地接公共GND。采样率≥25MSa/s，记录≥0.4秒；I²S格式16位有符号、每声道32位槽、标准一位延迟；双声道内容相同。
4. 先测LRCLK，目标约48kHz；BCLK约3.072MHz，BCLK/LRCLK比值64。以实测采样率计算吞吐量，不能把内部时钟/过采样当输出采样率。
5. 解码一个声道，对稳定声音做FFT，使用较长窗口/适当窗函数，观察32个基频。默认频率是MIDI60—91，即C4—G6的连续32个半音；准确表在voices32_results.json。
6. 选择“声部1”，点一次“降半音”：C4峰应移到B3，其余31个频率保持。再关闭声部32：G6峰和对应活动声部应消失，释放尾音后计数降到31。重新点32恢复。
7. 停止检测，确认普通琴片音色恢复；退出页面、断线或按机身K4/K5，也应停止。最长60秒自动停止。

设备OLED只有128像素、32个频带，不能用它数清32个相邻半音。以外部I²S长窗FFT为主要证据，OLED证明FPGA本地实时反馈。原厂规则要求独立发声单元、活跃单元×输出采样率以及现场多频谱峰与RTL佐证；本包按这三项准备，不冒充官方额外认证。[赛题原文](https://www.gowinsemi.com.cn/university/match2026)

若实测同时32声部、48kHz，振荡器采样吞吐量为1,536,000声部采样/秒。电脑仿真的实际I²S已检出32个基频，32正弦联合拟合残差约0.183%，每帧最多225/256时钟。这些是数字仿真证据，现场仍需采集实板文件。

## 五、延迟：先分清两个测点

### A. 压力片到I²S，测数字链路

四通道示波器的地夹全部接系统公共GND；10X、DC耦合：

|通道|探头尖端接哪里|作用|
|---|---|---|
|CH1|ADC模块AI0/AI1…对应的**压力分压中点信号**|输入动作时间；不是压力片3.3V供电端|
|CH2|MAX模块BCLK|解码位时钟|
|CH3|MAX模块LRC/LRCLK|声道/48kHz采样时间|
|CH4|MAX模块DIN|真实音频数据|

![数字链路测量接线](previews/示波器_数字链路接线.svg)

有MSO数字通道时，可将BCLK/LRCLK/DIN接数字通道、CH1留给压力电压。关闭曲目和其他声音，留至少1毫秒安静预触发段，单次触发CH1上升，先用20—40毫秒总记录。若导出模拟数字电平CSV，采样率仍需≥25MSa/s，不要只导出屏幕1000个显示点。

事先固定两种判据并保留原波形：①压力电压第一次明确偏离基线（示例+0.05V），②输入超过固件触发门限。当前ON_THRESHOLD为280个ADC码，对应增量电压为`280×实测VREF/4096`；不要把供电VDD自动当作VREF。输出同时记录第一个非零样本与固定幅值门限（示例|PCM|≥64）。主结论采用哪个判据必须预先写清，不能测完后移动起点来凑5ms。缓慢按压时，“首次动作”到“达到触发条件”的时间也会进入第一种判据。64是数字幅值计数，不等于可听阈值或50%包络。

假设CSV列为Time,CH1,CH2,CH3,CH4，时间单位秒、首行表头，在项目中运行：

```powershell
python scripts/lab_audio_inspect.py i2s "实测.csv" --out "实测结果" --input-step 0.05 --output-step 64
```

仪器导出的时间是毫秒时加`--time-scale 0.001`。表头不止一行时调整`--skip-rows`。列号从0开始，可用`--time --pressure --bclk --lrclk --din`指定。若逻辑分析仪导出0/1，使用`--logic-threshold 0.5`。脚本输出真实解码WAV、频谱峰和延迟JSON，不会代替未做的现场测量。

只分析32声部稳态I²S、没有压力信号时：

```powershell
python scripts/lab_audio_inspect.py i2s "32声部.csv" --bclk 1 --lrclk 2 --din 3 --logic-threshold 0.5 --spectrum-only --voices 32 --out "32声部实测"
```

`--voices 32`对默认32个基频逐一核对（至少0.30秒稳态数据，局部谱峰、相对最强峰不低于−30dB），任何一个缺失都报告失败；结果JSON保留每个目标/实测频率。4/8/16可改相同参数。它只证明这些谱峰同时存在，独立关断/变调仍按前面的现场步骤验证。声部已被手动改调时不要沿用默认32音表。

### B. 压力片到功放音频，测更完整的电气输出

**MAX98357A是桥接Class-D输出，SPK−/OUT−不是GND。普通示波器地夹绝不能接在SPK−。** 优先请老师用差分探头；没有差分探头时，四通道方案：CH1仍接压力信号，CH2尖端接SPK+/OUT+，CH3尖端接SPK−/OUT−，三根地夹全部接系统GND，数学通道CH2−CH3。先检查探头额定值和公共接地，不悬浮/断开示波器保护地。[MAX98357A原厂资料](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX98357A-MAX98357B.pdf)、[探头接地参考](https://www.tek.com/en/documents/whitepaper/abcs-probes-primer)

![功放差分测量接线](previews/示波器_功放差分接线.svg)

差分输出仍含高频PWM，不能把开关沿当声音已经开始。用仪器音频低通，或保存≥2MSa/s原始CSV后再低通提取音频。例：Time,CH1压力,CH2正端,CH3负端：

```powershell
python scripts/lab_audio_inspect.py speaker "功放实测.csv" --input-step 0.05 --output-step 0.02 --out "功放结果"
```

示例20mV输出门限应高于实测噪声底，并在测试前确定。脚本用511tap因果FIR低通，报告附加群延迟且**不自行扣除**；该结果包含测量滤波延迟。建议数字I²S与功放结果都保存，分别标注。用麦克风听喇叭还会加入传播时间，不能混作同一延迟。

### 重复与判定

中音区两种音色×七片，每种轻击、正常、较重击至少各若干次；正式记录每个固定工况20次，保留最小、最大和范围。再补最低C2、最高音区、开音效、已有多声部时的工况。记录供电、电压、音量、音效、温度、触发定义和探头设置。

只有**预先定义的整机输入→音频输出判据**全部满足目标，才写“实测<5ms”。固定256时钟调度和无队列积压不等于物理输入绝对零抖动；ADC扫描相位、传感器和模拟输出均有影响。测到超过5ms时保留失败样本，不删异常值。

## 六、三种音效和三维表情

口琴/二胡分别长按与轻重击；只改变一个量：力度看音量/频谱，滑杆看音高移动，颤音开关/深度看长音周期变化。旋钮普通状态音量，深度编辑按既有机身规则。回声、合唱、混响逐个启用，敲一个短音后放开，听重复尾音/音色厚度/空间尾响；对比同音量下的峰值与RMS，检查是否突然削顶或巨响。不能只听三种效果一起打开的混合声音。

现场可用设备录音分别导出干声、回声、合唱、混响，文件名写清音色、音区、音量和效果。内置8kHz回听有带宽和压缩限制；正式音质比较优先用I²S48kHz解码或合适的音频采集设备。
