# 声芯 Android App · 0.22 配套验收源码

配套FPGA为2026-11-02构建的A623完整音响版。主导航保持演奏、曲库、音色、创作、设备五栏；新增功能集中在“设备→演奏工具”和“曲库→曲谱书架”。本轮已通过JVM测试、Compose页面渲染、assembleDebug与lintDebug；本轮新增功能的真机/FPGA联调仍按验收手册逐项测试。

## 功能与执行边界

- 蓝牙连接后直接控制，无需机身K4/K5授权。手机发送指令，FPGA返回对应序号的状态/回复，App不把GATT写入成功视为设备已经执行。实时七键/十二音沿用状态合并和释放优先路径。
- 演奏工具提供实际FPGA最终音频的波形、1024点FFT频谱、单声道延迟相图，以及原32声部引擎的4/8/16/32声部诊断、独立音高和门控。App读取定期快照；OLED本地刷新。图形不是压力条模拟动画。
- 七片可选择C2—B7的精确音高，应用/回读/保存与恢复自然音；指引曲谱音高优先。手机十二音精确命令不受七片自定义表改变。
- 设备录音采集最终PCM，低通降至8kHz后IMA压缩，最长8秒；通过偏移、token和整段CRC16回传，在手机解码、回听及导出WAV。它不是实时无损音频流，也不是手机麦克风录音。
- 曲谱书架内置三首传统旋律，并支持有界HTTPS目录/JSON下载、文件导入、缓存、逐音编辑、试听、上传、自动演奏与亮灯跟弹。在线目录保留原站登录限制。照片识谱与录音分析沿用24项内置模型/资产，本轮未引入外部识别API，也未重新训练模型或声明新的识别准确率。
- 仅启用口琴与二胡；手碟/金属保留在此前0.21候选中。既有音色/传感标定保护项未改变；第7片满格和音质、供电、物理延迟仍需现场确认。

## 构建

需要JDK17、AndroidSDK36、Gradle8.13。先设置本机JAVA_HOME、ANDROID_HOME；如使用AndroidStudio，也可配置本地local.properties。执行：

```text
gradle :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

APK输出在app/build/outputs/apk/debug/app-debug.apk。自行重建的Debug签名可能与交付APK不同，不保证覆盖已安装版本；不要在保留数据前直接卸载。

## 验收

完整实验室步骤见原工作区docs/acceptance_lab_20261102.md，发行包内为“实验室验收手册.html”；新增协议见docs/product_tools_protocol.md或发行包“协议与实现说明.md”。先加载配套FS到SRAM，测试通过后再安排Flash。

先检查普通演奏/机身控制和两首曲目，再检查工具页图形、映射、设备录音回传、下载曲谱与离线识别。32声部使用外部I2S长窗FFT和独立变调/关断验证；OLED32频带不能代替32个相邻谱峰的辨认。延迟需保留原始仪器CSV，数字仿真不能代替整机实测。
